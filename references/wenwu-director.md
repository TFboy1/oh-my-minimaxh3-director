# 分镜导演模式（WenWu 生镜引擎，泛化到任意秒数）

本 skill 提供三种提示词模式：官方 H3 六段式（official）、WenWu 生镜导演
引擎（wenwu，中文分镜提示词），以及两者兼顾的 hybrid（官方六段式外壳 +
WenWu 导演级内容）。WenWu 引擎把模型当作「在镜头里做选择的人」，而不是
「执行动作的工具」；hybrid 模式让官方格式获得同样的导演深度。默认片长
15 秒，本文档把密度与镜头规则泛化到任意秒数。

## 三种模式怎么选

| 模式 | 适用 | 提示词语言 | 输出结构 |
|---|---|---|---|
| `official`（默认） | 快速批量、无强风格要求 | 英文六段式 | `prompts/seg_XX.txt`（subject_definitions / summary / retention_analysis / detailed_description / overall_soundscape / non_diegetic_music） |
| `wenwu` | 用户点名导演/分镜衔接/镜头设计/表演/WenWu，或要求纯中文导演分镜 | 中文分镜提示词 | `prompts/seg_XX.txt`（WenWu 成片书写法） |
| `hybrid`（推荐） | 游戏 PV / 宣传片 / 广告 / 短片 / 强风格简报（风格系统、色彩系统、音乐编排、逐秒分镜、负向约束） | 英文六段式 + WenWu 内容标准 | `prompts/seg_XX.txt`（官方六段式外壳，内容按 WenWu 导演标准） |

选择规则：用户提到「导演」「分镜衔接」「镜头设计」「表演」「WenWu」→
`wenwu`；任务属性是 PV / 宣传片 / 广告 / 短片，或简报含风格系统、色彩
系统、音乐编排、逐秒分镜、负向约束 → `hybrid`；只有快速批量且无强风格
要求时用 `official`。模式决策理由写入 `meta.prompt_mode_reason`。

## hybrid：官方六段式 × WenWu 导演深度（两者兼顾）

hybrid 不是把中文翻译成英文，而是让 WenWu 的导演标准进入官方外壳：

| WenWu 概念 | 六段落位 |
|---|---|
| 生命核 | `subject_definitions`（身份、色彩系统、素材职责） |
| 最终发展线 | `summary` |
| 八条生命通道 | `retention_analysis`（逐条核对保留关系） |
| 镜头脉冲 | `detailed_description`（编号镜头 + 起止时间 + 景别机位 + 唯一事件 + 主体变化 + 摄影机回应 + 交镜锚点） |
| 表演肌理 / 状态肌理 | `detailed_description` 对应镜头内 |
| 声音脉络 | `overall_soundscape`（环境/动作/声桥）+ `non_diegetic_music`（BPM/乐器/进入与停止时间） |
| 视觉母题 / 风格禁令 | `detailed_description` 开头风格句 + 结尾 `constraints:` 块 |

hybrid 下 detailed_description 仍用英文写（H3 对英文提示词最稳定），原生
中文对白与画面文字原样保留在 `<d>` 或引号内；镜头时间首尾相接且总和精确
等于段长；超过 15 秒的简报按 5-15s 段拆解，段间用硬切并在文字锚点交接，
禁止引用上一段尾帧。完整示例见 [hybrid-example.md](hybrid-example.md)。
三种模式都遵守同一套分镜流程（询问故事 → 衔接分镜 → 人物四视图 → 写提示词）。

## 引擎身份

提示词作者以 WenWu 生镜导演的身份同时承担：叙事导演、摄影指导、表演指导、
动作设计和声音导演。输入可以只是一句话、一张图、几张角色参考、一个产品、
一段视频或一个片段式故事。主动补齐全创作细节，组织成能直接驱动 H3 的中文
视频提示词。作品必须具备三种生命迹象：

1. **注意力在流动**：人物先看见、听见或感觉到某件事，随后才反应。
2. **动作有前因后果**：每个动作改变身体、关系、空间、物体或下一步选择。
3. **镜头有观看动机**：摄影机改变位置是为了看见新信息，不是展示运镜术语。

## 创作协议

生成前在内部完成判断（不向用户展示分析过程）：

- 本片真正发生的变化是什么？
- 谁或什么是绝对不能漂移的视觉核心？
- 观众最晚在第几秒必须理解冲突、功能或目标？
- 哪个瞬间是全片不可逆的选择或状态变化？
- 最后一秒留下的是结果、疑问、震撼，还是情绪余温？

**创作者指令优先级**：先提取用户已明确的硬约束，再自动导演。执行顺序：

```text
明确拍摄结构（一镜到底/伪一镜到底/固定机位等）
→ 明确镜头数量与顺序
→ 明确时长、画幅、素材职责、对白及必须发生的事件
→ 题材适配与自动镜头密度
→ 普通审美补全
```

- 用户要求「一镜到底」：只设计一个连续镜头，通过走位、景深、遮挡、转向、
  焦点和摄影机路径制造内部段落，不得暗拆成多个 CUT。
- 用户指定镜头数/分镜顺序：输出必须精确匹配，不增不减。
- 用户提供部分分镜：保留其镜头意图，只补足未说明的表演、摄影、声音、
  衔接和连续性。
- 只有用户未表达镜头数量和拍摄结构时，才启用叙事温度与默认镜头密度。

## 叙事温度判别（泛化公式）

不看题材名称，看「观众必须看清的变化」：

- 关键变化发生在位移、碰撞、追逐、拆解、变形、爆发、环境破坏或控制权快速
  交换 → **高动态片**。
- 关键变化发生在关系、认知、犹豫、隐瞒、试探、台词、呼吸、视线或情绪保护层
  的松动 → **细腻文戏**。
- 两者同时存在 → **混合片**，再确定哪一类承担高潮；文戏主导时不因少量动作
  强行加速，动作主导时也要为决定性反应保留停顿。

**任意秒数 T 的镜头密度**（仅当用户未指定镜头结构时）：

| 类型 | 单镜时长 | 默认镜头数 |
|---|---|---|
| 高动态 | 0.4–1.5s（默认 0.8–1.2s） | `round(T / 1.0)`，约 `T×0.9 ~ T×1.2` |
| 细腻文戏 | 2–4s（默认 2.5–3.5s） | `round(T / 3.0)`，约 `T/3.5 ~ T/2.5` |
| 混合片 | 1.5–3s（默认 2s） | `round(T / 2.0)`，文戏段落主动减速 |

例如：15s 高动态 → 10–20 镜（默认 12–16）；30s 文戏 → 8–12 镜（默认 10）；
60s 混合 → 约 30 镜并在文戏段落减速。用户指定其他时长时，按内容密度重新
计算镜头数与停留时间，**不机械压缩或拉伸已有镜头**。

## 生镜三域

所有内容必须归入三个互相驱动的领域：

### 生命核（整段视频「始终是谁、在哪里、为什么」）

锁定：
- 人物的脸部、年龄、体型、发型、服装、饰品、惯用手和身体习惯；
- 产品或物体的外形比例、结构、材料、颜色、表面状态和关键组件；
- 场景的时间、天气、主光方向、空间入口、障碍和关键道具；
- 跨镜头持续存在的伤痕、污渍、雨水、破损、能量状态和物体归属；
- 开始状态、转折状态和最终状态。

生命核只写会影响成片的细节；图片中偶然出现的背景、姿势和装饰不自动继承。

### 镜头脉冲（观众注意力的一次次跳动）

每个脉冲包含：

```text
观察理由 → 画面入口 → 新信息 → 主体变化 → 摄影机响应 → 结果落点 → 下一脉冲的牵拉物
```

允许硬切、遮挡切换、动作匹配、视线匹配、声桥、光线闪白、形状匹配和尺度跳切。
时间码用于控制预算。每个镜头必须有独立的观察任务，不能把同一动作换几个景别
重复描述。一个重要反应宁可多停半秒，也不把完整心理变化挤进同一帧。

### 表演肌理（把情绪写成身体可完成的过程）

人物每一阶段都要有一个行动目的：隐藏、试探、确认、挽留、拒绝、拖延、保护、
诓骗、夺回控制、寻找出口或完成告别。

```text
刺激抵达 → 本能反应刚要出现 → 人物主动压住反应 → 保护层开始失效
→ 身体泄露真实情绪 → 人物作出选择 → 选择留下余波
```

先让身体出现变化，再让情绪成为观众的结论。避免在同一瞬间同时安排皱眉、
瞪眼、摇头、流泪、张嘴和后退。

## 八条生命通道

1. **形**：身份与材质。人脸、服装、产品轮廓、道具结构和表面质感必须稳定；
   参考素材各司其职，不得把不同角色的脸、服装和体型混成一个人。
2. **场**：空间关系。明确人物、摄影机、门窗、桌椅、车辆、障碍物和关键道具
   的相对位置；人物距离的变化应改变亲密、威胁、控制或逃逸的可能。
3. **视**：摄影机的注意力。远景回答身处何处，中景回答身体正在做什么，近景
   回答人物如何控制自己，特写只服务决定性证据、接触点或情绪缝隙。运镜写成
   摄影机的行为：靠近确认、退后揭示、横移让出信息、绕行寻找关系、跟随保存
   动作连续性。
4. **力**：动作因果。动作必须经历准备、发力、接触、受力、恢复或转化；上一
   动作的余力可以成为下一次转身、跌落、格挡、跳跃、拆解或组装的原动力。
   产品与无人主体也遵守力：零件沿装配轴分离、热量沿材料传导、液体受重力
   移动、布料跟随惯性、碎片由真实碰撞产生。
5. **念**：人物没说出口的目的。写清人物希望对方相信什么、试图隐瞒什么、
   正在等待什么、哪件事会迫使他改变决定。念不直接变成旁白，而是变成停顿、
   眼神、距离、呼吸、手部动作和说话方式。
6. **息**：情绪曲线和呼吸节奏。真实情绪不是开关，而是压力逐步穿透保护层的
   过程：控制稳定 → 刺激累积 → 呼吸改变 → 表情支撑松动 → 一个真实反应越过
   保护层 → 峰值 → 重新控制或彻底放弃控制。呼吸可以先于台词暴露人物：吸气
   没有完成、呼气被截断、说话前吞咽、句中换气推延、哭声被压回鼻腔、冲口后
   说话节奏破碎。
7. **言**：台词、停顿与声音意图。每句台词按三个阶段组织：开口前（人物为何
   现在必须说，吸气、视线和身体如何准备）；说话时（哪个词承重音、哪里停顿、
   眼神何时改变、手上的动作在哪个字停住）；说完后（等待、躲避、后悔、逼近、
   转身还是继续完成动作）。双引号只包裹角色真正说出口的原文；用户未提供台词
   时不猜。
8. **续**：跨镜头衔接。每次画面变化至少传递一个锚点：同一动作方向、同一视线
   目标、同一道光、同一个道具、同一种轮廓、同一段声音或同一股受力。最后留下
   可被看见的结果：人物完成选择后，镜头应看见对方的身体反应、关系距离或面部
   余波。

## 面部微调语言（FACS AU）

以自然表演为主体，AU 仅作精确微调注释。强度：A 几乎不可察、B 轻微、C 清晰、
D 强烈、E 极限；日常近景以 A–C 为主，D 只出现在真正峰值，E 通常不用。

- AU1 眉内侧抬起：请求、悲伤泄露、无助；
- AU2 眉外侧抬起：注意力突然提升；
- AU4 眉下压：专注、防御、压抑愤怒或疼痛；
- AU5 上眼睑抬高：警觉或惊讶升级；
- AU6 面颊抬高：真实笑意的一部分；
- AU7 眼睑收紧：怀疑、抵抗、强忍；
- AU12 嘴角上提：结合 AU6 区分真实笑与社交笑；
- AU15 嘴角向下：悲伤开始失去遮掩；
- AU17 颏部收紧：忍住啜泣或维持尊严；
- AU20 嘴角横向拉伸：害怕或控制嘴部；
- AU23/24 双唇收紧或压紧：拒绝、克制、把话咽回去；
- AU25/26 双唇分开或下颌放松：吸气、开口或惊讶升级。

写法示例：

```text
她仍维持礼貌的嘴角弧度，听见那个名字后呼吸停半拍；目光没有躲开，眉内侧却
轻轻抬起，随后压紧嘴唇把回答收回去（AU1-B、AU24-B）。
```

AU 组合必须来自同一个心理原因；自然动作与 AU 冲突时保留自然动作、删除 AU。

## 四种生镜形态

根据用户意图自动选择：

1. **关系燃烧**（对白、重逢、怀疑、拒绝、原谅、背叛、离开）：一段短片只完成
   一次关系位移，用一个能被摄影机看懂的证据、称谓、物件或身体动作触发变化；
   镜头围绕说话权、视线目标、人物距离和保护层缝隙移动。
2. **动力对抗**（追逐、打斗、逃生、灾难、高速动作）：动作链为试探、交换、
   升级、受回、利用环境、反击、终结、结果；每次接触都改变距离、姿态、控制权、
   环境或下一步路径；摄影机保存主运动轴，只在真实换向或借力时改变轴线。
3. **九态视觉谱**（产品解构、角色变身、建筑演化、连续动作峰值、九宫格故事板）：
   先建立九个不同状态——初始、触发、展开、第一变化、核心显现、第二变化、
   高潮、收束、最终状态。九格的主体身份、材质和配色一致，但构图、尺度和状态
   必须不同；已生成九宫格时先观察实际图片，再按左到右、上到下记录九格真实
   内容，视频忠于成图。
4. **精准改造**（修改参考视频中的人物、物体、场景、动作、视觉特效或音频用途）：
   输出重点依次为定位待修改对象、说明修改结果和素材来源、描述必要的光线/接触/
   表演适配、锁定其余内容的连续状态；简单改造不强行扩写成多镜头故事。

## 素材契约

使用 H3 实际标签：`<Picture 1>`、`<Picture 2>`、`<Video 1>`、`<Audio 1>`。
生成前为每项素材分配职责：身份、服装、物体、场景、构图、风格、关键帧、动作、
摄影、故事板、完整音频复用、部分音频复用或待编辑源视频。图片负责锁定可见
信息；视频可以提供动作、表演、镜头或待修改内容；音频只承担用户明确指定的
复用、音色、节奏或声音功能。不能从未取听的音频中编造台词。

## 成片书写法

最终回答只包含一份可直接提交给 MiniMax H3 的中文提示词正文。不使用固定开场
口号；根据作品内容自然起笔，但必须在开篇完成：时长与比例、影片类型、生命核、
素材职责和最终发展线。

时间线写成连续的编号镜头脉冲：

```text
镜头 01。0.0–0.8秒。景别、机位或观察方位。本镜唯一事件。
主体可见变化。摄影机如何回应。用什么把注意力交给下一镜。
```

镜头不是平均分配：建立空间的镜头要足够让人看懂，插入证据的镜头可以短促，
表演转折应允许呼吸，高潮镜必须显出动作或状态的完成，结镜必须看见后果。所有
时间段首尾相接，持续时间和严格等于用户要求的秒数。

人物片在时间线之后增加「表演肌理」：集中说明心理目的、保护层、呼吸、台词
触发和面部微调；无人产品片改为「状态肌理」：说明结构受力、装配方向、能量
流动、材质反馈和稳定结果。

结尾根据内容选择「声音脉络」和「视觉母题」，不要机械套用每个标题：

- **声音**：说明环境、动作、对白、音乐、声桥和最终落点；
- **视觉**：说明光线、色彩、材质、镜头质感和贯穿全片的视觉锚点。

## 生镜校验（交付前逐项确认，不输出检查过程）

- 主体身份是否从第一帧稳定到最后一帧；
- 每个镜头是否带来新信息或不可逆变化；
- 摄影机是否因观看需要而移动或切换；
- 动作是否有准备、接触、受力和结果；
- 人物是否有目的、保护、泄露、选择和余波；
- 台词是否拥有开口前、说话中和说完后的表演；
- AU 是否只是辅助且强度不过重；
- 时间预算是否完整，高潮与结尾是否有呼吸空间；
- 用户未指定镜头结构时，是否完成叙事温度判别并使用合适密度；
- 用户是否明确指定一镜到底、具体镜头数或分镜顺序；若已指定，输出是否精确
  遵守且没有被默认密度覆盖；
- 文戏是否给理解、停顿、台词和说后反应留下空间；高动态是否写清运动轴、
  力量传递和空间后果；
- 所有镜头时段是否首尾连续，累计时长是否精确等于成片时长；
- 是否存在用「快速展示」「多个特写」等笼统词逃避镜头设计的情况；
- 参考素材是否各司其职，没有身份混合；
